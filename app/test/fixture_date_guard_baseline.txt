# rsh101 — hardcoded-fixture-date baseline (grep guard).
#
# Format: path:count:rationale (path is relative to `app/`; count is the
# number of *unmarked* hardcoded `'created_at': '<year>-…'` literals the
# file is currently allowed to carry). Lines starting with `#` are
# comments.
#
# Why this file exists. `imports_tab.dart:165-168` cuts the Auto-Imported
# and Skipped buckets off at 30 days measured against `DateTime.now()`.
# A fixture frozen at a literal date therefore passes until the wall
# clock drifts past that cutoff and then fails — silently reddening
# `flutter-test`, which is the root job every deploy job hangs off
# (`ci.yml:304`). That is exactly the failure that froze prod on image
# `c85e350` from 2026-04-26 to 2026-07-27.
#
# The 29 files below were already on that fuse when the guard landed.
# Sweeping them was explicitly out of scope for rsh101 (see the plan's
# "What we're NOT doing"); the baseline exists so that the *next* one to
# cross the cutoff is a known, enumerated risk rather than a surprise,
# and so no NEW file joins them.
#
# To fix a file rather than baseline it: mint the timestamp relative to
# `DateTime.now()` (see `_recent()` in
# `test/features/activity/imports_tab_test.dart`), or — if the fixture
# feeds an age-independent bucket (Needs Review / Failed, which the
# widget shows regardless of age) — append `// age-independent` to the
# line. Then ratchet the count here down; the guard fails if a count is
# stale in either direction.
#
# Adding a new entry, or raising a count, requires a code-review comment
# on the PR that does it.
