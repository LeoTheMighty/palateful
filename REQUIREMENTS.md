My requirements for this project are:
* Have a good place to store all of my recipes, iterate on those recipes, and share them with others.
* Be able to import my recipes from any kind of external source where I used to store them and then create recipes for each one.
* Be able to have a "Make Recipe" mode that is easy to use, to find the ingredients, and to go through the entire process.
* Have a good OCR system where we can import recipes from basically anywhere and then create a good working recipe based on it.
* Have a shared shopping cart system where I can have a realtime updated cart so that me and my partner don't double grab things.
* Have a shared calendar for meal planning.
* Have a public recipe system so that I can find recipes people put onto the app.

Additional Thoughts:
* Want AI to be super optional and to be able to opt-in for all the super AI features. 
    * OCR doesn't really count as AI, especially since I'm self-hosting and the whole "generate recipe" flow.
* Even when AI is used I want it to be as in the background, hidden but helpful (like a caterer vibe) so that it's consistent and reliable but not in your face.
