# Story MCP.2: Core Agent Tools (5 tools)

Status: ready-for-dev

## Story

As a user talking to Claude,
I want Claude to search my recipes, suggest new ones, add notes, check my pantry, and know my preferences,
so that Claude can be a knowledgeable cooking assistant without me opening the app.

## Acceptance Criteria

1. `search_recipes` — semantic search over user's recipes; params: query (req), max_results, max_cook_time, pantry_match
2. `suggest_recipe` — AI-generate from ingredients; params: ingredients (req), cuisine, meal_type, dietary_restrictions, difficulty
3. `add_note_to_recipe` — add a note; params: note_body (req), recipe_id OR recipe_name
4. `get_pantry` — pantry items; params: include_expired, expiring_within_days, category
5. `get_user_preferences` — dietary + cooking settings
6. All 5 tools visible in MCP tool listing and callable with valid JWT
7. Tool descriptions are product-copy quality (guide Claude on when/how to use)
8. Runs on worker thread via `call_agent_tool()` with context propagation

## Technical Approach

- Wrap existing `BaseTool.execute(db, user_id, **kwargs)` from `libraries/agent/agent/tools/`
- All async wrappers delegate to `mcp_server.server.call_agent_tool()` from MCP.1 (handles thread + contextvars)
- Tool parameter schemas generated by FastMCP from type hints
- Tool descriptions live in the docstring so they propagate to the client
